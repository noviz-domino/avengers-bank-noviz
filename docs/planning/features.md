# 기능 목록

> **팀이 FigJam에서 함께 만든 기능 목록(41개)입니다. 이 레포에서 실제로 구현하는 범위는 [scope.md](scope.md)를 보세요.** 대출은 빼고, 예산 관리([budget.md](budget.md))를 더했습니다.

## 기능 구조도

FigJam의 트리를 그대로 옮겼습니다. 대출은 FigJam에서 별도 흐름으로 그려져 있어 따로 적었습니다.

- **은행 웹·앱**
  - **회원**
    - 회원가입
    - 로그인: 아이디, 간편인증, 휴대폰인증, SNS 소셜 로그인
    - 로그아웃
  - **계좌**
    - 계좌 관리
      - 계좌 목록
      - 계좌 정지
      - 계좌 개설: 입출금 계좌 가입, 예금 가입, 적금 가입
    - 거래내역 조회
      - 필터: 금액별, 날짜별, 키워드
    - 거래내역 검색: 거래 상대방, 거래 유형
    - 이체
      - 계좌 이체: 송금 준비 → 사용자 승인 → 결과 확인
      - 수취인 관리: 수취인 등록, 별칭 저장, 최근 보낸 사람
      - 이체 한도: 1회 한도, 1일 한도 → 한도 설정(연장, 제한)
  - **카드**
    - 조회
      - 카드 목록 조회
      - 사용내역: 키워드 검색, 기간 검색, 매입매출
    - 사용 등록
    - 카드 가입: 신용카드, 체크카드
- **대출**: 대출 상품 조회 → 대출 한도 조회 → 대출 신청 → 대출 심사 → 대출 실행
- **자연어 입력·RAG**: 기능 트리에는 없고 [이용 흐름 ⑥](user-flows.md)에만 있습니다. 기능 명세를 추가해야 합니다.

## 기능 명세

### 계좌

| 순번 | 기능 | 세부 구현 내용 |
|---|---|---|
| 1 | 회원가입·로그인 | 회원가입, 로그인, JWT 인증, 로그아웃 |
| 2 | 계좌 관리 | 계좌 개설, 계좌 목록, 잔액 조회 |
| 3 | 계좌 이체 | 상대 계좌 조회, 송금, 이체 결과 확인 |
| 4 | 거래내역 조회 | 입출금 내역, 날짜·금액별 필터링 |
| 5 | 거래내역 검색 | 거래 상대방, 메모, 거래 유형 검색 |
| 6 | 입출금 알림 | 거래 발생 시 실시간 알림 |
| 7 | 자동이체 | 정기이체 등록, 수정, 해지 |
| 8 | 지출 통계 | 월별 지출, 카테고리별 분석 및 그래프 |

### 대출

| 순번 | 기능 | 세부 구현 내용 |
|---|---|---|
| 1 | 대출 상품 조회 | 신용대출, 전세자금대출, 주택담보대출 등 상품 목록, 금리, 한도, 가입 조건 조회 |
| 2 | 대출 상품 비교 | 상품별 금리, 대출 한도, 상환 방식, 대출 기간 비교 |
| 3 | 대출 한도 조회 | 소득, 신용점수, 기존 부채 정보를 기반으로 예상 대출 가능 금액 조회 |
| 4 | 대출 신청 | 대출 상품 선택, 신청 금액 및 기간 입력, 상환 방식 선택 |
| 5 | 대출 서류 제출 | 소득증빙서류, 재직증명서 등 서류 업로드 및 제출 상태 확인 |

| 7 | 대출 실행 | 대출 약정 확인, 사용자 인증, 대출금 지급 및 계좌 잔액 반영 |
| 8 | 대출 계좌 관리 | 대출 잔액, 적용 금리, 상환 기간, 다음 납입일 조회 |
| 9 | 대출 이자 계산 | 대출 원금, 금리, 기간에 따른 예상 이자 및 월 상환액 계산 |
| 10 | 상환 방식 시뮬레이션 | 원리금균등, 원금균등, 만기일시상환 방식별 월 납입액 및 총이자 비교 |
| 11 | 대출 상환 | 정기 상환, 상환 계좌 출금, 원금·이자 반영 및 상환내역 조회 |
| 12 | 중도 상환 | 일부·전액 조기 상환, 중도상환수수료 계산, 잔여 원금 갱신 |
| 13 | 상환 일정 관리 | 월별 상환 일정, 납입 예정액, 상환 완료·미납 현황 조회 |
| 14 | 대출 연체 관리 | 납입 지연 감지, 연체이자 계산, 연체 상태 및 알림 관리 |
| 15 | 대출 만기 관리 | 만기 예정 알림, 만기 상환, 대출 종료 및 계좌 상태 변경 |

## 정해야 할 것

- **필수/선택 구분:** 명세가 41개라 각자 전부 구현하기에는 많습니다. 기능마다 필수·선택을 표시하면 DB도 필수 기능 기준으로 확정할 수 있습니다.
- **자연어 입력·RAG 명세:** 지원할 의도(이체, 조회, 상품 질문 등), 되묻는 경우, RAG 문서 범위(약관, FAQ, 상품 설명).
- **구현 순서:** 과제에서 팀이 함께 정하기로 한 항목입니다.
