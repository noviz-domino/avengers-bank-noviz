# 0021. 디자인 값과 공통 UI 부품으로 화면 표현 통일

- 상태: 채택
- 날짜: 2026-11-09
- 관련: [디자인 인계](../design-drafts/HANDOFF.md), [공통 부품 사용법](../../frontend/ui.README.md)

## 배경

여러 작업자가 `styles.css`, `cards.css`, `products.css`, `settings.css`, 승인 창 내부 스타일을 따로 작성해 머리글·뒤로 가기·버튼·글자 크기가 화면마다 달라졌다. 홈 배너 제어는 기본 버튼으로 보였고, 긴 별칭은 가로 넘침을 만들었다. 6개 하단 탭은 선택한 홈 시안의 5개 탭과 달랐고, 계좌를 선택하기 전 계좌 탭은 고정 목적지가 없었다.

## 결정

`ui.css`를 첫 스타일시트로 읽고 크림·화이트·네이비, 입출금 블루·예적금 세이지·최근 거래 앰버, 글자 크기·여백·모서리·그림자·44px 터치 영역을 변수로 정의한다. 부품 CSS는 `ui-` 범위로 제한하고 `[hidden]`만 전역으로 적용해 체크카드 결제일처럼 숨겨야 하는 요소를 보장한다.

`ui.mjs`는 이스케이프된 HTML 문자열을 반환하는 순수 함수와 계좌번호 가림·포커스 복원 도우미를 제공한다. API 호출과 이벤트·라우팅은 기존 모듈이 담당한다. 신뢰하는 부품 HTML을 조합하는 인자는 `*Html`로 구별한다. 홈과 하단 탭부터 이관하고, 다른 화면은 2단계에 이 부품을 사용한다.

하단 탭은 시안대로 **홈·상품·AI 상담·카드·전체**로 복귀한다(2026-11-11 [ADR 0029](0029-layout-gutter-tabs-menu.md)에서 홈·계좌·카드·상품·AI 상담으로 바꾸고 전체는 머리글로 옮김). 전체는 기존 `#menu`로, 이체는 계좌 행·상세에서 들어간다. 홈은 공통 머리글, 잔액 눈 아이콘, 5초 자동 배너와 재생 제어, 접기 섹션, 가린 계좌번호, 최근 거래 전체보기, 질문 예시 AI 진입 카드를 사용한다. 승인 대기 배너와 없는 알림 기능은 추가하지 않는다.

## 검토한 대안

| 대안 | 장점 | 고르지 않은 이유 |
|---|---|---|
| 프레임워크·UI 라이브러리 도입 | 부품·상태 관리 도구를 활용할 수 있다 | 빌드 없는 ES 모듈 앱과 실제 API 흐름을 오늘 안에 옮기는 범위가 커진다 |
| 화면별 CSS만 수정 | 한 화면 수정은 빠르다 | 값과 마크업이 계속 복제되어 다음 병렬 작업에서 다시 달라진다 |
| 모든 기본 태그 스타일 재정의 | CSS 양이 적다 | 아직 이관하지 않은 카드·상품·승인 창에 회귀가 생긴다 |

## 결과

디자인 값과 마크업의 변경 지점이 모이며, 2단계 작업자는 [ui.README.md](../../frontend/ui.README.md)의 같은 계약으로 작업할 수 있다. 긴 별칭은 줄바꿈하고, 다시 그려도 같은 화면의 버튼 포커스를 유지한다. 기존 API·거래·세션 로직은 유지한다.

감수할 점은 2단계가 끝날 때까지 기존 화면과 새 부품 스타일이 함께 있다는 것이다. 실제 데이터의 계좌 수·금액·날짜는 시안과 다르고, 44px 터치 영역은 시안의 작은 시각적 버튼보다 넓다. 홈 그림은 시안에서 참고한 은행 일러스트를 별도 래스터 자산으로 보관한다.

팀 뼈대와의 차이: 이 레포의 모바일 웹에 공통 디자인 값과 HTML 부품 계층을 추가했다. 서버 구조·DB·API 규약은 바꾸지 않았다.
