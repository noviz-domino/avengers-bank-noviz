# 0031. 노비즈 뱅크 디자인 적용: 회청색 바탕과 흰 상자, 넓은 화면 두 칸 배치, 에이전트 진행 표시

- 상태: 채택
- 날짜: 2026-11-26
- 관련 PR: (이 문서를 추가하는 PR)
- 관련: [ADR 0021](0021-ui-components.md) 공통 부품, [ADR 0027](0027-compact-layout-chat-login.md) AI 상담 채팅형, [ADR 0029](0029-layout-gutter-tabs-menu.md) 여백·하단 탭, [ADR 0018](0018-chat-stream-router.md) 상담 스트리밍

## 배경

- 화면에 색이 너무 많았습니다. 크림색 예산 카드, 파란 배너, 회색 총자산 띠, 파랑·초록·주황 섹션 띠가 한 화면에 함께 있어 서로 다퉜습니다.
- 글꼴은 `Pretendard`를 첫 번째로 적어 두었지만 웹폰트를 불러오지 않아 Windows에서는 맑은 고딕으로 보였습니다.
- 화면은 휴대폰 폭(최대 480px) 한 줄로만 그려져 데스크톱으로 보면 좁은 기둥 하나에 나머지가 빈 화면이었습니다. 포트폴리오를 보는 사람은 대부분 데스크톱으로 봅니다.
- AI 상담이 지금 무엇을 하는지(라우터가 담당을 고르고 담당이 도구를 부르는 과정)는 말풍선 한 줄 안내로만 보였습니다.
- 이전 프로젝트 [langgraph-financial-agent](https://github.com/noviz-domino/langgraph-financial-agent)(노비즈 뱅크)의 화면이 이 문제들을 이미 풀고 있었습니다: 회청색 바탕에 흰 상자, 파랑 하나, 왼쪽 장부와 오른쪽 상담의 두 칸 배치, "지금 에이전트는" 단계 표시.

## 결정

1. **색 체계를 노비즈 뱅크 값으로** (`ui.css`의 디자인 값만 바꿈): 바탕 `--ui-bg` `#eef3fa`, 글자 `#172033`, 보조 글자 `#5d6b82`, 구분선 `#e3e9f2`, 강조 파랑 `#2f6bff`(옅은 면 `#e7eeff`, 글자용 `#2352cc`). 예금·적금 초록과 최근 거래 주황은 흰 바탕에서 읽히도록 진한 값(`#0f8a59`, `#a86500`)을 씁니다. `--ui-cream`은 이름만 남기고 옅은 회청색 면(`#f5f8fc`)으로 바꿨습니다. 모서리는 18px(작은 것 12px), 그림자는 거의 없앴습니다.
2. **Pretendard 웹폰트를 실제로 불러옴**: `index.html`, `benefits.html`, `protection.html`에서 jsDelivr의 Pretendard Variable을 불러옵니다(노비즈 뱅크와 같은 주소).
3. **홈·계좌 탭은 회청색 바탕 위에 흰 상자**: 입출금·예금적금·최근 거래 묶음을 흰 상자로 감싸고 섹션 머리의 색 띠를 없앴습니다. 색은 계좌 아이콘 타일(36px, 옅은 색 면) 한 곳에만 씁니다. 총자산은 파란 카드에 흰 글자로 바꿨습니다.
4. **좌우 여백을 모든 화면 20px로, 좁은 폰(420px 이하)에서는 이체 버튼을 금액 아래로**: 흰 상자의 안쪽 여백 때문에 계좌 이름이 "생활 / 비"처럼 끊겼습니다. 처음에는 홈·계좌 탭만 바깥 여백을 20px로 줄였는데 그러면 카드·상품 화면(36px)과 제목·내용의 폭이 달라 보였습니다. 그래서 공통 값 `--ui-page-gutter`를 36px에서 20px로(340px 이하는 24px에서 16px로) 바꿔 모든 화면이 같은 폭을 쓰게 했습니다. 노비즈 뱅크도 20px입니다. 좁은 화면에서는 이체 버튼을 금액 아래로 내립니다.
5. **넓은 화면(1024px 이상) 두 칸 배치**: 왼쪽은 지금 화면(480px), 오른쪽은 AI 상담을 늘 띄웁니다(`app.mjs`의 `desktop`, `.app.desk`). 상담이 오른쪽에 있으니 하단 탭의 "AI 상담"은 숨기고, 상담 탭(`#chat`)으로 오면 왼쪽은 홈을 보여 주고 상담 입력칸에 포커스를 둡니다. 왼쪽 화면이 바뀔 때마다 상담 칸도 다시 그려서 쓰던 글은 `draft`로 이어 붙입니다. 휴대폰 화면은 지금처럼 하단 탭으로 다닙니다.
6. **AI 상담 모양을 노비즈 뱅크 채팅으로**: AI 말풍선은 옅은 회청색 면, 내 말은 파랑, 예시는 점선 말풍선 대신 칩(누르면 입력칸에 채우는 동작은 그대로). 승인 대기는 파란 테두리 카드("승인이 필요해요" 표시 + 요약 + "내용 확인하고 PIN으로 승인")로 보여 줍니다. 버튼 문구에서 "이체"를 뺀 이유는 예금 신청·카드 정지 해제도 같은 버튼을 쓰기 때문입니다.
7. **에이전트 진행 표시**: 상담 머리 아래에 "담당 고르기 → 담당 확인 → 도구 실행 → 답변" 네 칸과 지금 하는 일 한 줄을 둡니다. 서버가 이미 보내던 `status` 이벤트(`routed`·`agent`·`tool`, ADR 0018)를 그대로 그려서 서버 코드는 바꾸지 않았습니다. 승인 대기를 만든 턴은 마지막 칸이 주황 "승인 대기"가 되고 "돈은 PIN으로 승인해야 움직여요"라고 알려 줍니다(`chat.mjs`의 `stepsHtml`).

## 검토한 대안

| 대안 | 장점 | 고르지 않은 이유 |
|---|---|---|
| 노비즈 뱅크 화면(`web/index.html`)을 통째로 옮기기 | 똑같은 모양 | 화면이 하나뿐인 시연용이라 계좌·카드·상품·이체 화면을 담을 수 없음. 색과 배치 원칙만 가져옴 |
| 모든 화면을 회청색 바탕 + 흰 상자로 | 화면마다 같은 느낌 | 카드·상품·설정은 화면별 CSS가 흰 바탕을 전제로 짜여 있어 한 번에 바꾸면 깨질 곳이 많음. 디자인 값만 바뀌어도 색은 통일됨. 홈·계좌 탭부터 |
| 어두운 모드도 같이 | 노비즈 뱅크에 있던 기능 | 화면별 CSS에 흰색 등 고정 색이 많아 지금 넣으면 반쯤 깨진 어두운 화면이 됨. 고정 색을 디자인 값으로 옮긴 뒤에 |
| 넓은 화면에서 상담을 떠 있는 창(오른쪽 아래 버튼)으로 | 화면 구조를 거의 안 바꿈 | 에이전트가 일하는 모습이 늘 보여야 포트폴리오 목적에 맞음. 노비즈 뱅크처럼 붙박이 칸으로 |
| 진행 단계에 도구 이름(`get_my_accounts`)을 그대로 | 개발자에게 정확 | 사용자 화면이라 서버가 주는 한국어 안내(`label`)를 씀. 도구 이름은 Langfuse 추적에서 봄 |

## 결과

- 좋아지는 점: 색이 파랑 하나로 정리되고 글꼴이 의도한 Pretendard로 보입니다. 데스크톱에서 왼쪽 화면과 오른쪽 상담을 함께 보며 잔액 확인과 상담을 오갈 수 있습니다. 상담이 라우터 → 담당 → 도구 순서로 움직이는 것이 화면에 드러납니다.
- 감수할 점: 홈·계좌 탭과 나머지 화면의 바탕색이 다릅니다(다음 단계에서 맞춤). 좁은 폰에서는 이체 버튼이 금액 아래로 내려가 계좌 한 줄이 조금 높아집니다. 웹폰트를 외부 주소(jsDelivr)에서 받아 처음 열 때 글꼴 파일을 한 번 내려받습니다.
- 팀 뼈대와의 차이: 팀 뼈대에는 모바일 웹이 없습니다. 이 문서는 이 레포의 ADR 0021·0027·0029의 색과 상담 모양을 바꿉니다.
