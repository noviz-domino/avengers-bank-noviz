# 0012. 입출금 계좌 해지: 잔액 0·연결 카드 없음, 해지 뒤 환불은 상담원이

- 상태: 채택
- 날짜: 2026-11-06
- 관련 PR: (이 문서를 추가하는 PR)
- 관련: [ADR 0010](0010-card-payments.md) 카드 결제, [ADR 0011](0011-card-bills.md) 대금 출금, [ERD](../ERD.md) "승인이 필요한 것과 바로 실행하는 것"

## 결정

1. **`POST /accounts/{id}/close`는 입출금 계좌만, 잔액이 0일 때만 바로 해지한다**(ERD에 정해 둔 대로, PIN 없음). 남은 돈은 먼저 이체(PIN 승인)로 옮긴다. 예·적금 해지(만기·중도)는 범위 밖이다(scope.md).
2. **이 계좌를 결제 계좌로 쓰는 카드가 쓸 수 있는 상태(`ACTIVE`·`SUSPENDED`)면 해지하지 않는다**(`409 LINKED_CARD_EXISTS`). 분실(`LOST`) 카드만 남아 있으면 된다.
3. **연결 카드에 안 낸 신용 사용분(`UNBILLED`·`BILLED`)이 있으면 분실 카드라도 해지하지 않는다**(`409 CARD_UNPAID`). 대금이 나갈 계좌가 사라지지 않게.
4. **해지 뒤 들어온 결제 취소는 받아 두고 "환불 대기"로 남긴다.** 해지한 계좌로는 돈을 넣지 않는다. 응답의 `refund_pending: true`와 메시지로 알린다.
5. **환불 대기는 상담원이 고객 요청을 확인한 뒤, 카드 주인의 다른 입출금 계좌로 보낸다.** 이 레포에는 상담원 역할이 없어서, 대금 출금과 같은 **서버 키 시스템 API**로 만든다: `GET /system/card-refunds`(목록), `POST /system/card-refunds/{card_tx_id}`(`to_account_id`).
6. **잠금 순서는 연결 카드 → 계좌**다(ERD 규칙 5). 해지는 카드를 검사하기 전에 계좌까지 잠근다. 카드 발급도 결제 계좌를 잠가서, 해지 중인 계좌로 카드가 발급되지 않는다.
7. 실행 함수(`execute_card_ledger`)는 환불도 `ACTIVE` 계좌로만 넣는다.

## 배경

- 계좌 상태에 `CLOSED`는 있었지만 해지 API가 없었다(TODO).
- 카드 결제·대금 출금은 결제 계좌가 있다고 가정한다. 리뷰(PR #16, #17)에서 "해지된 계좌로 환불되면 돈이 묶인다", "대금이 나갈 계좌가 없으면 영원히 연체"가 나왔다.
- 해지 뒤에도 가맹점 취소는 올 수 있다. 실제 은행은 이런 돈을 상담 절차로 다른 계좌에 보낸다(사용자 결정).

## 검토한 대안

### 연결 카드

| 대안 | 결과 |
|---|---|
| **쓸 수 있는 카드·안 낸 대금이 있으면 막기** | **채택**. 카드 API를 새로 만들지 않음 |
| 해지할 때 연결 카드도 함께 해지(`TERMINATED` 추가) | 카드 상태·마이그레이션이 늘고, 안 낸 대금이 있으면 어차피 막아야 함. 버림 |

### 해지 뒤 환불

| 대안 | 결과 |
|---|---|
| 해지한 계좌에 그대로 넣기 | 해지 계좌는 목록에 안 보여서 돈을 꺼낼 방법이 없음. 버림 |
| 자동으로 다른 입출금 계좌로 | 고객이 모르는 계좌로 돈이 갈 수 있음. 버림 (사용자 결정) |
| 최근 결제가 있으면 해지 막기 | 기간을 정해야 하고, 그 뒤의 취소는 여전히 갈 곳이 없음. 버림 |
| **환불 대기 + 상담원이 고객 확인 후 다른 계좌로** | **채택** (사용자 결정) |

## 결과

**좋아지는 점**
- 대금이 나갈 계좌가 사라지지 않는다. ADR 0010·0011에 남겨 둔 "계좌 해지 때 같이 다룬다"가 해결된다.
- 해지 뒤 취소도 돈이 사라지지 않고 목록에 남는다.

**감수할 점**
- 결제 계좌를 바꾸는 API가 없어서, 카드를 쓰는 계좌를 해지하려면 카드를 분실 신고해야 한다. 카드 해지·결제 계좌 변경은 나중에.
- 상담원 역할·고객 확인 기록이 없다. 서버 키를 가진 쪽이 상담원 역할을 한다. 누가 어떤 요청으로 보냈는지는 감사 기록(`audit_logs`)에 아직 남기지 않는다.
- 해지 계좌의 거래내역은 계좌 상세·검색으로 계속 볼 수 있다(목록에서만 빠짐).
- 동시성은 PostgreSQL `FOR UPDATE`에 기대고, SQLite 테스트로는 증명하지 않았다.

**팀 뼈대와의 차이**
- 팀 뼈대: 해지 없음 → 이 레포: 잔액 0·연결 카드 검사 후 바로 해지, 환불 대기와 상담원 시스템 API
