# 개발 기록 (트러블슈팅)

개발하다 부딪힌 문제를 **문제 → 어떻게 알았나 → 원인 → 해결 → 배운 점** 순서로 남깁니다. 포트폴리오와 [회고](../retrospective.md)에 그대로 옮겨 쓸 수 있게, 증거(로그·캡처·측정값)와 관련 PR·ADR을 같이 적습니다.

- 설계를 왜 그렇게 정했는지는 [ADR](../decisions/README.md), 코드 설명은 [코드 가이드](../guides/README.md)에 있습니다. 여기는 **"무엇이 잘못됐고 어떻게 찾았나"**를 남기는 곳입니다.
- 캡처는 [`images/`](images/)에 `날짜-주제-번호.png`로 둡니다.
- 상태: ✅ 해결 · 🔍 원인만 파악(수정 전) · ⏳ 진행 중
