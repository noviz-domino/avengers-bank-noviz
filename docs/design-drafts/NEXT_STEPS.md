# 다음 작업 — 다른 컴퓨터에서 이어가기

작성일: 2026-11-08 (Asia/Seoul)

## 바로 다음에 할 일

**홈과 계좌 화면에서 이미 결정한 수정부터 이미지에 반영합니다.** 새로운 디자인 방향을 다시 고르거나 프론트엔드를 구현하는 단계부터 시작하지 않습니다.

1. [최신 홈 14번](14-home-compact-privacy-latest.png)에서 **승인 대기 중인 이체 안내 영역을 제거**하고 남은 영역의 간격을 정리합니다.
2. [선택한 계좌 화면 29번](29-account-detail-option-3.png)에서 하단의 별도 **계좌 정보** 진입 영역을 제거합니다. 계좌 정보·별칭 변경·해지는 오른쪽 위 관리로 통합하고 하단 고정 이체 버튼은 유지합니다.
3. 수정본을 사용자에게 보여주고 새 파일로 저장합니다. 기존 시안은 보존하고 README·manifest·HANDOFF의 최신 기준 링크를 갱신합니다.

완료 기준: 홈에 승인 대기 안내가 없고, 계좌 관리 진입이 중복되지 않으며, 선택한 색상·정렬·여백은 유지되어야 합니다.

## 다음에도 유지할 선택

- 상품은 1번, AI 상담은 3번, 전체 메뉴는 2번, 계좌는 3번입니다.
- 카드는 1번·3번 보기 방식을 선택할 수 있게 하는 방향입니다. 카드 혜택 메뉴도 필요합니다.
- 이체 최신 기준은 **39~43번**입니다. 토스 참조의 받는 계좌 → 금액 → 확인 → 6자리 PIN → 완료 흐름이며 상단 로고는 없고 은행명 옆 작은 로고는 유지합니다.
- 크림·화이트·네이비, 입출금 블루 / 예적금 세이지 / 최근 거래 앰버, 좌우 약 24px, 잔액 오른쪽 정렬을 유지합니다.
- 음성 입력, 주변 카드 혜택 추천, 팀원 은행 간 이체는 후속 아이디어입니다. 현재 화면에 임의로 추가하지 않습니다.
- 상세 선택과 최신 이미지 링크는 [HANDOFF.md](HANDOFF.md)를 기준으로 봅니다.

## 저장·Git 작업 방식

- 사용자는 선택·미선택 시안과 수정본을 모두 한 폴더에 보관하길 원합니다. 새 이미지는 이 `docs/design-drafts/`에 의미 있는 파일명으로 저장합니다.
- 원본 이미지 폴더가 다른 컴퓨터에 없어도 레포 안의 이미지를 참조할 수 있습니다. 기존 파일을 덮어쓰지 말고 수정본과 선택 기록을 추가합니다.
- 변경은 별도 브랜치에서 커밋하고 PR로 올립니다. PR #26은 시안 43개·결정·인계 문서를 보관한 기록으로 병합되어 있습니다.
- 새 PR의 병합은 사용자가 요청했을 때 진행합니다. 앱 코드가 바뀌는 구현 단계에서는 관련 테스트를 실행합니다.
