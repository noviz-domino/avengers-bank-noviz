# 카드 전용 데모

기존 모바일 데모와 같은 정적 서버에서 `/cards.html`을 엽니다. 저장소 루트에서 Git Bash로 실행:

```bash
python -m http.server 4173 --directory frontend
```

브라우저 주소: <http://localhost:4173/cards.html>

- 시안 21의 크게 보기와 23의 목록 보기를 전환하고 카드를 선택합니다. 선택한 카드의 이용금액·계좌·내역·혜택·관리가 함께 바뀝니다.
- 기본은 크게 보기이며 보기 방식·선택 카드·관리 상태는 메모리에만 저장합니다. 새로고침하면 초기화합니다.
- 2026년 11월 고정 데모입니다. 월 합계는 표시하는 해당 월 전체 내역에서 계산하며, 최근 내역은 3건만 표시합니다. 신용 미결제액은 전월 사용액도 포함한 별도 예시입니다.
- 이용내역 / 카드 혜택 / 카드 관리 순서이며 한도 확인은 카드 관리 안에 있습니다. 혜택 설명은 `src/avengers_bank/seed.py`의 데모 상품과 같습니다. 할인 실적 집계는 제공하지 않습니다.
- 일시정지·분실 신고는 확인 대화상자 이후 카드 데모 상태에만 반영됩니다. 정지 해제·재발급·신규 발급·실제 결제·API 연결은 포함하지 않습니다.

## 공통 앱 연결

`app.mjs`의 카드 메뉴(`#cards`)에서 `mountCards(root, { cards, embedded: true })`를 빈 전용 컨테이너에 호출합니다. 반환된 정리 함수를 화면 교체 전에 호출합니다. 공통 `styles.css`와 카드 전용 `cards.css`를 함께 로드합니다. 카드 클래스는 `cards-` 접두사를 사용합니다.

통합 화면은 공통 데모 표시와 하단 메뉴를 사용합니다. 상태 배열을 앱에서 보관해 정지·분실은 메뉴 왕복 후에도 유지하며, 보기 방식·선택 카드는 재진입 시 초기화합니다. 로그아웃·새로고침하면 모두 초기화합니다. 카드의 계좌 이름·이용내역은 독립 고정 예시이며 공통 계좌의 별칭·잔액·거래내역과 동기화하지 않습니다. 원본은 카드 커밋 `c8d9fb1`입니다.
